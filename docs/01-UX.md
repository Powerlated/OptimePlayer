There should be an option where the user can sort songs in the library, in both ascending and descending order:
 * By name
 * By length

Ensure that when a new song is loaded, the library continues to follow the sort that the user has selected, without the user having to select it again.

The length of a song is defined as such:
 * For repeating songs, it is the length of the intro plus two plays of the repeating section.
 * For non-repeating songs, it is simply the length of the song. 

In the library, the length of each song should be displayed next to the song's name, in text that has less contrast than the song's name.

GBA and NDS should both feature separate high-shelf filters adjustable by these parameters:
 * Filter order
 * Filter q
 * Cutoff frequency
 * Gain
